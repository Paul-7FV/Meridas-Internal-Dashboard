# Meridas-Internal-Dashboard
Meridas Internal Dashboard est une solution propriétaire de gestion et de suivi de performances conçue exclusivement pour l'agence Meridas Incubator.  C'est le premier outil du genre dans l'industrie du clipping, remplaçant les méthodes de suivi archaïques par une interface web fluide, sécurisée et orientée data.
